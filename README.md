# cw-style-skill-creator — Package any writing style as a reusable AI skill

> Capture a specific writing voice and package it as a reusable style guide Claude can follow. Built for AI consumption — directive commands and examples, not explanations.

[![OpenClaw Skill](https://img.shields.io/badge/OpenClaw-Skill-blueviolet)](https://github.com/NachaFromMars)

## Overview
cw-style-skill-creator builds style guides that teach Claude a specific writing style. Because the audience is an AI rather than a human reader, it favors directive commands and concrete examples over explanatory prose. Output in two formats: a quick single `.md` file, or a full structured `.skill` package that's validated and includes reference files. Every guide follows a consistent four-section structure.

## Features
- **Two output formats** — simple `.md` or full validated `.skill` package
- **AI-targeted** — directive commands + examples, not explanations
- **Four sections** — Voice & Tone / Sentence Mechanics / Paragraph Patterns / What to Avoid
- Output feeds directly into [cw-prose-writing](https://github.com/NachaFromMars/cw-prose-writing)

## Usage / Quick Start
Describe the writing style you want to capture. Choose simple `.md` for quick use, or `.skill` package for structured, long-term use.
